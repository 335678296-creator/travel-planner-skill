# 路线设计方法论 + 调研 SOP（做攻略的前半段）

需求收敛后、画看板之前，先用这套方法把路线和酒店定下来。全部来自冰岛 13 天项目实战。

## 路线设计五原则

1. **季节硬约束先行**——排任何行程前先查目的地的季节事实：日照时长（冰岛 1 月白天仅约 4 小时，每天只能排 2-3 个点）、路况（冰雪封路）、班次（有些航班/船每周仅两班）、营业状态（餐厅周几开、景点冬季是否开放）。这些直接决定行程骨架。
2. **单向不回头**——能不走回头路就不走（雷市进、向东一路玩到冰河湖再折返是反例；正确是单向顺路）。跨国段把"去不了直飞"的城市放最后或砍掉，别硬塞。
3. **住宿跟着次日景点走**——选酒店的第一标准不是颜值，是"离第二天第一个景点多远"。实战案例：Skálakot 赢在离次日瀑布群 25 分钟，Torfhús 再美也要开 1.5 小时，直接出局。颜值和口碑是第二关。
4. **高强度项目岔开排**——凌晨 6 小时极光团和次日 07:00 观鲸不能连着；长途驾驶日不接早班机。老板的原话："这两天岔开，不累吗？"
5. **旺季先锁房，后排行程**——旺季热门房型（蓝湖 Retreat 这类）提前 1.5 个月就紧张，且官网常有"两晚起订"等规则会反过来改变行程天数。**住宿预订优先级永远高于景点预约**，且优先选可免费取消的。

## 调研 SOP（每个目的地通用）

- **口碑**：小红书搜"地名+酒店/景点"看真实评价和出片效果；注意辨别软广
- **距离**：Google Maps 逐一核实"酒店→次日景点"的实际车程，不接受直线距离
- **条款**：酒店官网查含早/取消/起订晚数；代理库存（官网售罄但携程有房）必须点进详情确认条款差异
- **比价**：按 `board-format.md` 的酒店比价行规范执行（官网/Booking/携程同口径）
- **配图**：Wikimedia Commons API 搜图，每张 curl 验证 HTTP 200，图必须和地点对得上
- **所有价格和事实标注调研日期**（如"9/24 官网实时价"），汇率写口径行

## 决策留痕

- 用户拍板的 → 看板写 ✅；给了方案没拍板的 → ⏳ 待定；**放弃的选项不要删干净**，HTML 注释留档（冰岛项目直升机火山团放弃后留注释，方便反悔时找回）
- 每次大方向调整（改日期、换城市、增减晚数）→ 重排全链路住宿和交通，别只改局部
