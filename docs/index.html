🧳 AI 旅行攻略提示词包

4 张指令卡，按顺序粘给任何 AI（Kimi / ChatGPT / 豆包 / Claude……）
就能做出「路线合理 + 酒店会比价 + 行程一目了然」的完整攻略

✈️ 任何 AI 通用📋 一键复制🆓 免费
1启动 · 先让 AI 了解你别让它直接开写
我要做一份旅行攻略。开工前你不要急着写行程，先当我的旅行顾问， 按下面的顺序分批问我问题（一次最多问 5 个，我已经说过的不要重复问）： 1. 硬约束：出发地、目的地、日期、天数、人数（几间房）、 已经出票/付款不能退的航班和项目 2. 预算和住宿：机票舱位和酒店单晚预算、酒店还是民宿、 有没有必住的酒店、有没有积分或高端信用卡权益可用 3. 旅行风格：打卡出片还是深度慢游？每天想排几个景点？ 有什么绝对不做的（比如不早起、不坐船）？吃饭有什么要求？ 4. 谁负责订：我自己订还是有人帮我订？最终我要在线文档还是 PDF？ 问完之后，把我的所有要求复述一遍让我确认，我确认了你再开始做。
2出路线 · 确认需求后发五原则
好，按你确认的需求做路线方案，必须遵守这些原则： 1. 先查这个季节目的地的硬条件：白天几个小时、天气路况、 航班班次、景点和餐厅冬/夏季是否开放——这些决定行程骨架 2. 单向顺路走，不走回头路 3. 每个酒店的第一选择标准：离"第二天的第一个景点"近， 颜值和口碑排第二 4. 累人的项目（通宵极光、长时间车程）前后要隔开， 长途驾驶日不接早班机 5. 旺季先锁酒店再排行程，优先选可以免费取消的 输出：每一天去哪、怎么去、住哪，附理由。 所有信息标注你的调研日期。先给方案我拍板，别一次写死。
3酒店比价 · 逐家酒店发同口径对比
现在帮我做酒店比价，规则如下： 1. 同一家酒店给三列：官网价 / Booking价 / 携程价，最后给"建议在哪订" 2. 必须同口径对比：含不含早餐、能不能免费取消，条款不一样的 低价没有意义，要换算成同条款再比 3. 如果官网没房但携程有，那是代理房，点进去确认早餐和取消条款 跟官网一不一样，再下结论 4. 价格都标上查询日期和汇率 5. 顺便给我：这家酒店到第二天景点的实际车程、 小红书上的真实口碑、几张实景图的获取方式
4出成品 · 全部定了以后发全表格行程单
把最终行程做成一张全表格的行程单，要求： 1. 顶部一张总表：项目 | 日期时间 | 状态（已订/未订/待定）| 预约入口链接 | 确认号留白 2. 下面每天一张表：时间 | 去哪（中英文+一句话介绍）| 怎么去 | 花多久 | 状态 3. 每个景点和酒店都附 Google 地图搜索链接， 格式：https://www.google.com/maps/search/?api=1&query=地名英文 4. 餐厅单独标出，注明要不要订位、提前多久订 5. 已定的写✅，待定的写⏳，别替我拍板 6. 最后附一页：费用汇总表 + 出发前待办清单（按紧急程度排序）

💡 让效果翻倍的 5 个小技巧

  • 1️⃣ 一段一段来：别想着一条 prompt 出全套，AI 一步一步做质量高得多
  • 2️⃣ 给它看你的票根：已订的航班、酒店截图直接发给 AI，让它围着这些锚点排
  • 3️⃣ 不满意就说人话："南岸我想多住一晚""这个酒店换一家"，改方向很正常
  • 4️⃣ 要求标注日期：AI 查的价格都让它写查询日期，一个月后还知道新不新
  • 5️⃣ 最后让它自查：发一句"把费用合计算一遍，检查每段交通时间对不对"
